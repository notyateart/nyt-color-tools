# NYT Color Tools

![AI-Assisted Code](/ai.png)

A browser-based collection of color utilities for UI design.

Access here: https://notyateart.github.io/nyt-color-tools




## Included Tools:

### Gradient Step Generator
Generate swatches from smooth color transitions using OKLCH or HEX input.

### Quick Palette Generator
Quickly generate perceptually uniform color palettes.

### Figma Design System Palette Generator
Build sophisticated color palettes for design systems. Based on the principles of perceptually uniform color spaces but with more creative freedom while still keeping everything consistent. With the ability to save, download, upload and export to Figma.",




## Development

Run the project locally with `npm install` and `npm run dev`.

Parts of this project have been made with Generative AI.
